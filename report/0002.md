## Conclusion (honest)
**Training-free MC-RM does NOT improve recall on a pretrained mamba2 — it is neutral-to-negative.**
This is expected, not an implementation bug:
- The frozen model was never trained with a **segment-reset + summed-cache read-out**; adding cached
  contributions before RMSNorm distorts the output scale. RM is "free" only for memories *trained*
  that way (the MC paper's setting).
- The synthetic tasks use **random token IDs**, which are OOD for a text-pretrained LM (vanilla
  passkey is already at the noise floor). A clean training-free test needs a **natural-language
  passkey** (in-distribution).

→ Motivates **Phase 1** (train the GRM gate / SSC router; backbone frozen) and a **real-text passkey**
eval. The mechanism + loader are verified and ready for both.
