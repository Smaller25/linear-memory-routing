# 0018 — Axis-1 information-density segmentation: a real but fragile signal, not a mechanism (2026-06-28)

After 0016 (unsupervised boundary learning fails three ways), axis-1 reframed the problem: don't *learn
a per-token classifier*, **threshold the backbone's own information-density signal** (surprisal /
predictive entropy / adjacent-state cosine distance) calibrated to a target firing rate. Two learned
scalars, no oracle (`chunk-mode density`, `lmr/mosc/mosc_model.py`). Same recipe as 0015/0016
(irregular MQAR `--ctx-filler 128`, GDN-2 d256/4L, train-kv 4–64, eval 64–256, target-rate 0.15).

## The decisive measurement (threshold-free top-k(p) ∩ facts)
| | kv64 | kv128 | kv256 | recall | boundaries fired |
|---|---|---|---|---|---|
| 0016 unsupervised (reference) | 0.00 | 0.00 | 0.00 | 0.00 | — |
| **density surprisal, fixed-0.5** (1289–91) | **0.39** | **0.40** | **0.41** | 0.00 | **0** |
| density surprisal, quantile (1292) | 0.01 | 0.01 | 0.02 | 0.00 | ~ρT |
| density entropy, quantile (1293) | 0.12 | 0.13 | 0.15 | 0.00 | ~ρT |
| density cosdist, quantile (1294) | 0.06 | 0.08 | 0.12 | 0.00 | ~ρT |
| supervised learned (ceiling, 0015) | 1.00 | 1.00 | 1.00 | ~1.0 | =#facts |

## What happened — two regimes, both fail, and the *reason* is the finding
**(a) The intrinsic signal is real but partial.** With the fixed-0.5 cutoff, `p` sat diffuse near the
target rate (<0.5) so **zero hard boundaries fired** → empty cache → recall 0. But the backbone then
trained ≈vanilla, and its **raw surprisal ranks facts at 0.40** (kv-stable) — far above the 0016
unsupervised 0.00 and ~2.5× the random baseline (~#facts/seqlen ≈ 0.16). So a task-trained backbone's
surprisal genuinely localizes the unpredictable fact tokens. Entropy is weaker (0.2–0.3), cosine
distance near-random (0.1).

**(b) Using the signal as a hard selector destroys it.** Switching to a **quantile** cutoff (fire the
top-ρ fraction per row — exactly ~ρT boundaries, the right *count*) finally engages the cache, but
recall stays 0 **and the surprisal ranking collapses 0.40 → 0.01**. Co-training a hard sparse cache on
the density signal lets the gradient drift the backbone so that density no longer correlates with facts
— the boundaries fire at the right *rate* but the *wrong positions*. The act of using the signal as a
selector removes the very correlation it depended on: a self-defeating dynamic.

## Verdict
Axis-1 does **not** crack unsupervised boundary discovery. The premise has partial merit — intrinsic
surprisal carries ~0.40 of the fact-location information for free — but the signal is (i) too weak to
drive a hard cache on its own and (ii) **not robust to co-training**, which drifts it away from facts.
This is consistent with 0016: the discrete where-to-cut signal needs an anchor that co-training cannot
erode. The **supervised method (0015/0017) remains the only one that places boundaries on facts**
(top-k(p) = 1.00).

## What this rules in / out for next steps
- **Frozen-signal probe (most promising):** compute the density from a *frozen* backbone (or stop-grad
  the density path) so co-training cannot drift it; read a cache over its 0.40-precision boundaries.
  Tests whether the partial signal, *protected*, yields partial recall.
- **Reconstruction anchor:** make a segment "good" if its summary reconstructs its tokens — an anchor
  that ties density to content and resists drift (0016 menu item 5, still untried).
- **Not worth re-running:** entropy / cosine-distance as-is (both below surprisal at every kv).
