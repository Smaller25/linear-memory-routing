# 0001 — Memory Caching scaffold on FLA Mamba2 (2026-06-15)

## Goal
Stand up the Memory-Caching (MC) mechanism on FLA's `Mamba2ForCausalLM` so we can test whether
cached recurrent-state checkpoints + read-out routing (RM → GRM → SSC, with a MoM comparison arm)
close the linear-model recall gap — starting with the **training-free MC-RM** on pretrained
mamba2-1.3b.

## What landed
- **`lmr/ssd_scan.py`** — pure-torch SSD scan exposing `initial_states` (the chunk-level seed that
  FLA's `torch_forward` hardcodes to zero). Jointly linear in `(input, state)`.
- **`lmr/segment_runner.py`** — runs an FLA Mamba2 model segment-by-segment, caches frozen final
  SSM states, and reconstructs each cached checkpoint's contribution via the zeroed-input scan.
  Backends: `naive` (CPU) and `cuda` (`mamba_ssm.mamba_chunk_scan_combined`).
- **`lmr/readout.py`** — RM (training-free sum), GRM (`W_u` + sigmoid gate), SSC (top-k router +
  load-balance aux, adapting MoM's `load_balancing_loss_func`).
- **`lmr/converter.py`** — `state-spaces/mamba2-*` → FLA weights + GPU logit-match harness.
- **`lmr/mom_adapter.py`**, **`lmr/tasks/{mqar,niah}.py`**, **`lmr/scripts/*`**.

## Verification
CPU (this environment, `pytest tests/lmr` → 11 passed, 4 skipped): (i) scan linearity
`scan(x,h0)=scan(x,0)+scan(0,h0)` — the mathematical foundation of RM; (ii) read-out head
behaviour (RM sum, GRM/SSC shapes + aux); (iii) converter key-rename; (iv) MoM arm builds.

GPU-gated (skipped here, run on the A100): the segment runner reproduces FLA's own mixer
forward, and MC-RM reduces to vanilla at one segment (`run_segmented_lm` == `model().logits`).
These need a forwardable FLA model — FLA's mixer activation (Triton `swish`) and fused RMSNorm
have no CPU kernel in this build.

## Deferred to local A100 (no GPU / HF=403 here)
Converter logit-match against `mamba_ssm`; Phase-0 vanilla-vs-+MC-RM recall curves
(`run_baseline.py`); Phase-1 GRM/SSC training; Phase-2 MoM + Gated DeltaNet; Phase-3 real recall.

## Open risk
Converter key-mapping vs. the real `state-spaces/mamba2-1.3b` checkpoint is unverifiable here;
mitigated by the GPU-gated logit-match. The MC numerics are proven on CPU, so a converter fix
cannot invalidate the mechanism.
