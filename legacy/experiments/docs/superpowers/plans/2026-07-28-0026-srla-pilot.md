# 0026 SRLA Pilot — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 사용자 스펙 `docs/superpowers/specs/2026-07-28-0026-retrieval-improvement.md` (rev2)를 구현·검증한다 — frozen 30B GDN2 backbone 위에 **학습되는** state router(`W_desc`, `W_q`, `Φ_align`)를 얹어, 0025가 지목한 "router에 학습 신호가 없다 / descriptor가 backbone 읽기 기하와 불일치" 두 가설을 실측으로 가른다.

**0024/0025와의 관계 (이 실험이 새로 보는 것):**
- 0025까지는 **사후 재채점**만 했다 (학습된 mean-pool descriptor 고정, 점수식만 교체). `u:=q`·centering·PC1 제거 전부 무효.
- 0026은 backbone을 얼린 채 router를 **실제로 학습**한다. supervised chunk-index CE는 "미선택 chunk로 gradient가 안 간다"는 0025의 진단을 정면으로 겨냥한다.
- 융합 방식도 다르다: MC-SSC의 출력단 cached read → **state 가산 융합** `S_curr + Σα·Φ_align(S_m)`. `Φ_align`이 delta-rule 읽기 기하 보정의 자리.
- 0024/0025가 측정하지 않은 **TTFT / full-window PPL**을 처음 본다 (이 방법의 존재 이유).

**Architecture:** 별도 브랜치 `sh/srla` (0025 작업과 분리). backbone은 pinned checkout import (long-gdn `e71713e`, fla `4b02d15d`) — vendoring 금지. 실행은 **로컬 greenbeard SLURM** (VESSL은 0025 X4 전용).

## Global Constraints

- **사용자 스펙 rev2가 최상위.** 특히: (i) `L_c=2048`은 **전체 context 길이**, chunk 크기는 별도 `L_chunk`(기본 256) — 2048을 chunk로 하드코딩 금지; (ii) **router query는 입력 토큰별** (`q_t`마다 Sim/top-K/softmax/융합, 인과성 `m < chunk(t)`), chunk 평균 query 폐기
- 실행: 로컬 `sbatch -p main --gres=gpu:rtx6000:1` (6h 캡 → checkpoint/resume 필수), `env_common.sh` source, 대용량은 `/data2/sohyung/`
- **backbone 완전 freeze**; 학습 파라미터는 `W_desc`, `W_q`, `Φ_align` (+ K/V LoRA는 flag, 기본 off)
- 0025 영역(`lmr/analysis/260725_mc_niah_analysis/`, `report/`) 수정 금지
- 커밋 트레일러: `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`; .sh/.sbatch는 `git add -f`

### Task 1: 코어 모듈 + CPU 테스트

**Files:** `src/modules/descriptor.py`, `src/modules/router.py`, `src/modules/cache.py`, `tests/test_srla_modules.py`

- [ ] `BaseStateDescriptor` (추상: `forward(keys, chunk_bounds) -> [M, d_desc]`, `d_desc` 프로퍼티) + `AverageKeyDescriptor` (`mean_{t∈C_m} k_t` — 알려진 약한 baseline) + `HybridKeyDescriptor` 인터페이스 스텁 (`[k_energy ‖ k_max ‖ h_state]`, Phase 2)
- [ ] `StateRouter`: `W_desc`, `W_q`, `Φ_align`, τ; **per-token** cosine Sim → `TopK_{m<chunk(t)}` → softmax → `S_fused^(t) = S_curr^(t) + Σ α·Φ_align(S_m)`. `topk=0`/fusion-off 시 정확히 no-op
- [ ] `StateCacheManager`: chunk state `S_m [H,K,V]` + descriptor `D_m` 저장, CPU/GPU offload, top-K 인덱싱, eviction
- [ ] CPU 테스트 (백본 없이 통과, `MC_LONGGDN_WORKTREE` 없으면 skip 가드): descriptor 계약·교체 가능성, **per-token 인과성**(t는 자기 chunk 이전만), cache 저장/회수/eviction, router no-op 동등성
